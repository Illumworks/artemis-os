Typography

Two font families: --font-sans = Inter/Segoe UI and --font-mono = JetBrains Mono/SF Mono. --font-display aliases --font-sans. No explicit type scale — sizes are ad-hoc per component (9px–22px found in CSS).

⚠ Inconsistency  Font weights found across CSS: 300, 400, 500, 600, 650, 700, 800 — 7 distinct values. No named weight tokens exist (e.g. --weight-bold). Font sizes range from 8.5px to 22px with no systematic scale.

Iconography

App icons (PNG, used for PWA install and favicons). UI icons are inline SVG or Unicode glyphs — no icon font or sprite system. SVG icons are unsystematized: drawn inline per-component with varying viewBox and stroke widths.
