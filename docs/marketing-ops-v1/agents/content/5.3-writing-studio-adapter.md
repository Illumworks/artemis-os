# Component 5.3 — Writing Studio Adapter

**Deterministic integration component.** No LLM. POSTs assembled briefs to Writing Studio's `/drafts` endpoint, one call per deliverable.

## Purpose

The integration boundary between Artemis OS and Writing Studio. Take the immutable campaign brief + asset bundle from `campaign_workspaces`, transform into Writing Studio's payload format, POST one draft request per deliverable type.

## Trigger

Fires after 5.2 Asset Selector completes. Synchronous.

## Inputs

- `campaign_workspaces.campaign_brief` (set by 5.1)
- `campaign_workspaces.asset_bundle` (set by 5.2)
- Deliverable types to generate — for v1: configurable per campaign_type, default behavior:
  - `OBC` → `email`, `social`, `long_form`
  - `biliteracy` → `email`, `social`
  - `dyslexia` → `email`, `social`
  - `general_growth` → `email`

## Outputs

- One POST to Writing Studio per deliverable type
- `campaign_workspaces.writing_studio_drafts` (JSONB array, appended one entry per successful POST)
- `campaign_workspaces.status` → `sent_to_writing_studio` (on all successes) or `content_preparation_failed` (on any unrecoverable failure)

## API contract

See `schemas/writing-studio-draft.md` for the full POST /drafts payload. Endpoint URL in `.env`:

```
WRITING_STUDIO_URL=https://writing-studio.amira-internal.example.com
WRITING_STUDIO_API_KEY=...
```

## Per-deliverable retry logic

For each deliverable type:

```python
for attempt in range(1, 6):  # 5 attempts max
    response = http.post(f"{WRITING_STUDIO_URL}/drafts", json=payload, timeout=30)
    if response.status_code == 200:
        record_draft(workspace_id, deliverable_type, response.json()["draft_id"])
        break
    elif response.status_code == 429:
        sleep(response.json().get("retry_after_seconds", 60))
    elif 500 <= response.status_code < 600:
        sleep(EXPONENTIAL_BACKOFF[attempt])  # 10, 30, 60, 300, 1800 seconds
    else:  # 4xx other than 429 — malformed brief, do not retry
        fail_workspace(workspace_id, response.json())
        return
else:
    # 5 retries exhausted
    fail_workspace(workspace_id, "Writing Studio unreachable after 5 attempts")
```

## Failure modes

- **Writing Studio unreachable / 5xx** — exponential backoff up to 5 attempts. Final failure → `content_preparation_failed`, alert.
- **Writing Studio returns 4xx other than 429** — do NOT retry. The brief is malformed; alert with response body. Mark workspace `content_preparation_failed`.
- **Writing Studio returns 200 but missing `draft_id`** — treat as failure; alert.
- **Partial success (e.g., 2 of 3 deliverables succeeded)** — record successes in `writing_studio_drafts`. Mark workspace `content_preparation_failed` with `partial_success` flag. Operator decides whether to retry just the failed deliverable manually.
- **Auth token expired / 401** — fail loudly; alert. Token rotation is a manual ops process in v1.

## DB tables touched

- `campaign_workspaces` (read + write)

## Implementation notes for Codex

- Pure HTTP integration. Test with a mock Writing Studio server before pointing at real one.
- No retry on 4xx (other than 429). The brief is malformed; retrying won't fix it.
- Use `httpx.AsyncClient` for parallelism if 3+ deliverables. For v1 most campaigns have 1–3 deliverables; sequential is fine.
- Logging: log every POST attempt with workspace_id, deliverable_type, response status. Critical for debugging Writing Studio integration issues.
- The Writing Studio API contract is owned by Writing Studio team; we adapt to it. If they change the schema, this adapter is the only place to update.
