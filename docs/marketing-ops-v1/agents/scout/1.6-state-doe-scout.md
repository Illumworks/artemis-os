# Agent 1.6 — State DoE Scout

Watches each priority state's Department of Education, governor's office, and state board of education for guidance documents, mandates, supplemental funding announcements, and gubernatorial directives.

**discovered_by value:** `state_doe_scout`

## Purpose

Catch the layer between federal funding and district-level action — state guidance, state mandates, gubernatorial directives, state board votes.

## Cadence

- Daily poll across all priority-state DoE sites + governor sites + state board feeds.

## Inputs

- **Per-state DoE site** — RSS where available, web scraping where not. Per-state config in `services/state_doe_sources.py`.
- **Governor's office RSS** — per-state config.
- **State board of education meeting agendas** — per-state config (often PDFs).
- **Territory Config**
- **Reason Code Registry**
- **PDF Extractor service** (for state guidance PDFs)

## Outputs

Signals with `discovered_by = "state_doe_scout"`.

Source types: `state_doe`, `governor_press`, or `district_press` (for state-board agenda items linkable to specific districts).

Reason codes:
- `STATE_GUIDANCE_ISSUED`
- `STATE_MANDATE_ISSUED`
- `GUBERNATORIAL_EO_LITERACY`
- `STATE_OBC_LEGISLATION` (when DoE implements OBC framework following legislation)
- `STATE_DYSLEXIA_MANDATE`
- `STATE_BILITERACY_INITIATIVE`

## Urgency tiers (this scout)

- **hot** — Gubernatorial EO on literacy / curriculum, OR state mandate (binding) issued
- **standard** — non-binding state guidance, state board agenda mentions
- **enrichment** — state DoE announcements without near-term implementation

## Prompt scaffolding (deltas)

```
You are the State DoE Scout. You cover the policy implementation layer —
what state agencies do AFTER legislation passes.

Two deltas from generic scout prompt:

1. DISTINGUISH GUIDANCE FROM MANDATE.
   State DoE often issues non-binding guidance documents AND binding mandates.
   Tag distinctly:
     STATE_GUIDANCE_ISSUED  — non-binding, watch
     STATE_MANDATE_ISSUED   — binding, hot

2. WATCH EXECUTIVE ORDERS SPECIALLY.
   Gubernatorial EOs on literacy / curriculum are high-urgency signals — they
   often move faster than legislation. Emit as hot regardless of standard tier rules.

Same dedupe, same evidence quality bar.
For PDF-sourced guidance documents, set source_quality_low flag if PDF extractor
quality_score < 0.5.
```

## Failure modes

- **State DoE site redesigns** — expect 1–2 per year per state. Budget maintenance time. Site-down monitoring should alert immediately.
- **PDF guidance docs with poor OCR** — flag `source_quality_low`. Do not emit garbage text as the verbatim snippet. If OCR fails entirely, write to `unresolved_signals` for manual review.
- **Governor posts to social media before official site** — accept the lag. We are not a real-time news service.
- **RSS feed exists but is empty / stale** — log warning, fall back to scraping `doe_scrape_url`.

## DB tables touched

- `signal_queue`, `memory_layer`, `districts`, `unresolved_signals`, `reason_code_registry`, `territory_config`

## Implementation notes for Codex

- Build a single scraper class with per-state strategies. Avoid per-state duplicated code.
- Cache HTTP responses by URL hash for 1 hour. Many DoE pages serve the same content for days.
- For state board agendas, district-specific items may exist (e.g., "Approval of Pinellas County waiver request"). Resolve those to district_id when possible; otherwise emit at state level.
- Use Claude Haiku for reason code classification (high volume). Sonnet only when guidance is ambiguous between mandate / guidance — that distinction matters for urgency tier.
