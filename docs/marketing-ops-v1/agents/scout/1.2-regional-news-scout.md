# Agent 1.2 — Regional News Scout

News, board minutes, state DoE, supe transitions. Lower volume, higher signal-to-noise than 1.1. Often the leading indicator — board minute precedes RFP.

**discovered_by value:** `regional_news_scout`

## Purpose

Catch signals Starbridge misses. Often the leading indicator. Some overlap with newer scouts (1.6, 1.8, 1.9) is expected and intentional — multi-source confirmation is a feature, not a bug.

## Cadence

- Scheduled daily (board minutes are weekly cadence at fastest)
- Event-driven for high-priority sources (DoE press, gubernatorial directives)

## Inputs

- News API (`https://newsapi.org` or similar — `.env` key: `NEWS_API_KEY`)
- Board meeting minutes (per-district adapters, shared with 1.8)
- State DoE updates (shared fetcher with 1.6)
- Superintendent transition announcements (shared lens with 1.9)
- Regional news (paywalls flagged)

## Outputs

Signals with `discovered_by = "regional_news_scout"`.

Source types: `news_article`, `board_minutes`, `state_doe`, `district_press`.

## Urgency tiers (this scout)

Conservative with hot priority. Speculation = standard. Reserve hot for:
- Formal RFPs
- Board votes (passed)
- Official transitions (announced)
- Gubernatorial directives

## Tools required

```python
news_api.search(district_name: str, keywords: list[str], date_range) -> list[Article]
board_minutes.fetch(district_id, date_range) -> list[Meeting]   # shared with 1.8
state_doe.fetch(state, date_range) -> list[DocItem]              # shared with 1.6
pdf_extractor.extract(url) -> ExtractedPDF
```

## Prompt scaffolding (deltas from Starbridge generic)

```
You are the Regional News Scout. You catch what Starbridge misses.

Three deltas from generic scout prompt:

1. QUOTE ATTRIBUTION MATTERS MORE.
   Speaker attribution required when a person speaks:
   "Supt. [name], 2026-04-12 board meeting"

2. DISTINGUISH PROPOSED FROM ENACTED.
   BOARD_OBC_DISCUSSION vs BOARD_OBC_RFP_APPROVED.

3. CONSERVATIVE WITH HOT PRIORITY.
   Speculation = standard. Hot only for formal RFPs, board votes,
   official transitions, gubernatorial directives.

Same dedupe, same evidence quality bar.
```

## Failure modes

- PDF extraction garbage from scanned image → emit `source_quality_low` flag.
- Article paywalled → flag `evidence_quote_partial`, link to source URL.
- Same event covered by 5 outlets → dedupe by event signature via embedding similarity (suppress similar > 0.92).
- News API rate limit → fall back to RSS-only mode for the day.

## DB tables touched

- `signal_queue`, `memory_layer`, `districts`, `unresolved_signals`, `reason_code_registry`, `territory_config`

## Implementation notes for Codex

- This scout has the broadest source coverage. Don't try to optimize each source individually — use the shared fetchers from 1.6 (state DoE), 1.8 (board minutes), and 1.9 (LinkedIn).
- The Regional News Scout's unique contribution vs. the newer scouts: news APIs (paid + free) catching coverage in regional press that the official-source scouts won't have.
- Pre-filter news articles by district name + relevant keywords before sending to LLM. Cuts cost significantly.
- Use Claude Haiku for reason code classification (high volume); Sonnet for speaker attribution from board minute extracts (lower volume, higher stakes).
